# RuangKata

Platform untuk bagikan kata-kata indah dengan musik dari Spotify.

## Features
- User Authentication (Supabase)
- Create Kata-kata dengan musik Spotify
- Share link ke orang lain
- Gallery public
- Edit & Delete kata-kata
- Comments & Reactions

## Tech Stack
- Frontend: React 18 + Vite + Tailwind CSS
- Backend: Express + Supabase
- Music: Spotify Web API
- State: Zustand

## Setup

```bash
npm install
npm run dev
```

Visit: http://localhost:5173
